# mwala-zm/homebrew-tap

Homebrew formulae for [mwala-zm](https://github.com/mwala-zm)'s tools.

```sh
brew install mwala-zm/tap/gitenv
```

Formulae here are written by each project's release workflow; do not edit
them by hand. The template for gitenv lives in
[mwala-zm/gitenv/packaging](https://github.com/mwala-zm/gitenv/tree/main/packaging).
